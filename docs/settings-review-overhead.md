# Settings review — Overhead (top-down)

Generated by `tools/gen-settings-review.js`, parsed from `OH_WORLD_SETTINGS._render()`
in `js/overhead/overhead-settings.js` — the overhead panel has **no schema**, so there is
nowhere to store a tier or help text today. Same review method as the 2D list: fill
`Your call`, note regroups in `Move to`.

There is **no advanced tier in overhead yet** — the `Rec` column is a proposal, and
adopting it means converting this panel to a schema like the 2D one (which also gives it
per-setting help text, and makes the user guide generatable).
