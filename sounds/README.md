# Sound Effects

Place sound effect files here. Supported formats: .mp3, .wav

Expected files:
- mining.mp3 — plays when a block is mined (0.3-0.5s)
- attack-sword.mp3 — plays when player attacks (0.2-0.4s)
- mob-zombie.mp3 — zombie ambient sound (0.5-1s)
- mob-skeleton.mp3 — skeleton ambient sound (0.5-1s)
- mob-creeper.mp3 — creeper hissing sound (0.5-1s)
- mob-blaze.mp3 — blaze ambient sound (0.5-1s)
- mob-enderman.mp3 — enderman ambient sound (0.5-1s)
- explosion-tnt.mp3 — TNT explosion (0.8-1s)
- explosion-creeper.mp3 — creeper explosion (0.8-1s)

All files are optional. Missing files are silently skipped.
